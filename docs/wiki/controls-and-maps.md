# Controls And Maps

[简体中文](controls-and-maps.zh-cn.md) · [Player Guide](home.md)

Click inside the arena to capture the mouse. Move with WASD, jump with Space and crouch with Ctrl. Tab opens the scoreboard. In a Classic round, B opens the buy menu. F4 ends the buy phase early in a bot match.

| Arena | How to recognise it |
| --- | --- |
| Range | Raised platforms at both ends and a long east corridor |
| Depot | Container lanes and an overhead steel walkway |
| Skyline | A central steel platform on a rooftop |
| Patio | A courtyard with balconies and connecting alleys |

## Round Rules

Classic uses the buy phase and round economy. The normal target is nine rounds, with a two-round lead required after 8–8. In Mirror, both players receive the same rotating loadout at the start of each round. In Escalation, a round win advances that player's equipment tier. Completing the sequence wins the match. In a multiplayer room, the host selects the mode for both peers.
