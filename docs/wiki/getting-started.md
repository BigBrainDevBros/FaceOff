# Getting Started

[简体中文](getting-started.zh-cn.md) · [Player Guide](home.md)

Open Practice on a desktop browser to play a local opponent. Click inside the game to capture the mouse, use WASD to move and Tab to view the score. In a bot match F4 ends the buy phase early. Ranked requires a player account. To play with a friend, choose Rooms and exchange the room code.

| Arena | Landmark |
| --- | --- |
| Range | Raised end platforms and a long east corridor |
| Depot | Container lanes beneath a steel walkway |
| Skyline | A central platform on a rooftop |
| Patio | A courtyard surrounded by balconies and alleys |
