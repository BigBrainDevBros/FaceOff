# 入门指南

[English](getting-started.md) · [玩家指南](home.zh-cn.md)

在桌面浏览器中打开练习模式即可与本地电脑对手对局。点击游戏画面锁定鼠标，使用 WASD 移动，按 Tab 查看比分。在电脑对局中按 F4 可以提前结束购买阶段。排位模式需要玩家账号；与好友联机时，选择房间模式并交换房间码。

| 地图 | 场景特征 |
| --- | --- |
| 靶场 Range | 两端高台和东侧长廊 |
| 货场 Depot | 钢制走道下方的集装箱通道 |
| 天台 Skyline | 屋顶中央的平台 |
| 庭院 Patio | 阳台和巷道环绕的庭院 |
