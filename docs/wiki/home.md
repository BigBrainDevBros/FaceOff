# FaceOff Player Guide

[简体中文](home.zh-cn.md) · [Play FaceOff](https://bigbraindevbros.github.io/FaceOff/)

Use a desktop browser with a keyboard and mouse. Open Practice to choose a map and bot difficulty. Click the game view to capture the mouse. A duel starts with a buy phase. A player normally wins by reaching nine rounds. At eight rounds each, play continues until someone leads by two.

## Maps And Opponents

Start on Range to practise short and long sightlines. Use the same map when comparing bot difficulties. Note the arena, difficulty and positions when reporting a bot stuck against scenery. Include the approach direction and whether the problem repeats after restarting the round.

## Playing With A Friend

One player hosts a room and shares its five-character code. Both players should open the same build. If joining fails, use the network diagnostics or manual invite and answer codes. For a match discrepancy, record what each player saw and the round it occurred in.
