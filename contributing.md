# Contributing To FaceOff

[简体中文](contributing.zh-cn.md)

Serve the repository root with `python3 -m http.server 8000 --bind 127.0.0.1`. Open the local page in a desktop browser. Keep the asset packs and loader together.

For interface changes, start a match in the affected mode, exercise the settings or controls you changed, then return to the menu. For online changes, test a host and a joining peer on the same build. Record the browser, mode, observed result and any unavailable checks in the pull request.

Preserve the credits and third-party notices in the distribution. Update corresponding English and Chinese documentation together. Use three lowercase words after the commit type, for example `docs: explain duel modes`. Record user-facing changes under Unreleased. Use SemVer for releases and arrange peer review for shared game or network changes.
